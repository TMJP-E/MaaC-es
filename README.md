# ¿Cómo construir el universo?

Un manual de matemáticas que explica los fundamentos de las matemáticas y va más allá, con el objetivo de enseñar matemáticas de una manera diferente al enfoque pragmático utilizado comúnmente.

También es un proyecto, parte de una serie de desarrollos, que se mencionarán más adelante. _MaaC_ está planeado de una manera que me permite aprender y utilizar herramientas como Obsidian, TypeScript, Quartz, Jenkins, GitHub Pages y Slack.

Esta versión del proyecto es la traducción al _Español_.
